# 1_Visão geral
Esse é um sistema que busca auxiliar lojas menores com estoque e vendas,surgindo de uma iniciativa minha Gustavo representando a Solutech uma iniciativa privada que busca planejar toda a TI de uma empresa

# 2_O que o sistema faz?
O sistema é um sistema de vendas padrão, nele sera feito a venda e o controle de estoque. 
Tendo 2 Telas, uma para realização de caixa da loja, venda, troco e etc. E outra o cadastro de mercadoria, para monitoramento das mesmas.
Esse sistema é acompanhado de uma planilha a qual ele completa automaticamente no google sheets, podendo ter uma melhor visão para o dono entender perdas, vendas e lucro.
